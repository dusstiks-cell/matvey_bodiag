Проект: Матвей Бодяг Наш проект представляет собой многостраничный веб-сайт. Его основная задача — презентовать команду разработчиков, рассказать о предлагаемых товарах (мерче), а также предоставить пользователям удобный способ связи с нами.

Структура проекта index.html — Главная страница сайта с основной информацией и картинкой. about.html — Страница с информацией о каждом разработчике (фото, ФИО, возраст) contact.html — Страница с контактными данными (адрес и номер телефона). price.html — Страница с каталогом мерча (названия, картинки, описания и стоимость). project.html — Страница с информацией о проектах, над которыми работали разработчики. Над проектом работают: Полина — создание главной страницы (index.html). Маша — создание страницы контактов (contact.html). Лиза — создание страницы о команде (about.html). Женя — создание страницы с мерчем (price.html). Даша— создание файла документации (read.me).
